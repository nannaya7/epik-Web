# 에픽바이오 홈페이지

최신 로컬 수정본입니다.<br>
별도 설치나 빌드 없이 `index.html`을 브라우저에서 열어 실행할 수 있습니다.

## 서버 업데이트

`index.html`, `styles.css`, `refinements.css`, `app.js`와 `images` 폴더를 서버 웹 루트에 함께 업로드하세요.<br>
`server-upload.zip`에는 이 실행 파일들만 포함되어 있습니다.

## 반영 사항

- 사명: 에픽바이오 / epik bio.co.
- 홈페이지 색상에 맞춘 청록·민트 로고
- 첫 화면: 바이오마커를 읽고, AI로 진단의 미래를 열어갑니다.
- 상단 문의 메뉴: 협업문의
- 첫 화면 버튼: 핵심분야 살펴보기
- 회사소개, 바이오마커·AI 연구, 진단 소프트웨어, 향후 키트·장치 개발 및 생산 계획
- 연구소 소개 섹션 삭제
- 모바일 메뉴, 기술 설명 탭, 개발분야 펼쳐보기

## 모바일 화면

같은 주소에서 화면 너비에 맞춰 모바일·태블릿 화면으로 자동 전환됩니다.

- 800px 이하: 펼침 메뉴, 문구 아래 첫 화면 이미지, 세로형 연구·개발 분야, 한 열 문의 폼
- 600px 이하: 화면에 맞춰 제목 줄바꿈, 회사소개 원칙을 세로 목록으로 표시
- 입력칸 16px 글자, 터치 영역 확대, 화면 안전 영역 반영
- 메뉴는 링크 선택, 바깥 클릭, Escape, 데스크톱 크기로 전환할 때 닫힘
- Chrome에서 320·360·375·390·430·600·768·800·801·1024·1440px 화면의 가로 넘침과 주요 동작 확인

## 이미지 후보

현재 적용된 배경은 `images/hero-human.webp`입니다.<br>
`design-assets/hero-options`에는 연구자 협업 이미지 5장, 자연·AI 이미지, 자연·AI·DNA 이미지가 있습니다.<br>
이 후보들은 아직 홈페이지에 적용하지 않았습니다.<br>
`images` 폴더에 원본 로고와 색상 수정 로고도 함께 보관했습니다.

## 문의 기능

입력 내용을 복사하는 기능입니다.<br>
이메일 발송과 서버 저장은 연결되어 있지 않습니다.

## 로컬 미리보기

프로젝트 폴더에서 다음 명령을 실행하세요.

```powershell
python -m http.server 4173
```

실행 후 [로컬 미리보기](http://localhost:4173)에 접속하세요.

- 홈페이지 문구: `index.html`에서 수정
- 기술 탭 문구: `app.js`에서 수정
